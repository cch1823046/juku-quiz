📋 手順

1
テンプレートのCSVファイルをダウンロードして Googleスプレッドシート または Excel で開く
2
問題を追加・編集する（1行目の見出しは変えないこと！）
科目は math / sci / soc / eng / jpn のいずれかを入力
3
Googleスプレッドシートの場合：ファイル → 共有 → ウェブに公開 → CSV でURLを取得
または「公開CSVのURL」を下の欄に貼り付け
4
「読み込む」ボタンを押す。問題が自動的に取り込まれる

📊 CSVの列の形式

1列目: 科目 → math / sci / soc / eng / jpn
2列目: レベル → 1（低学年）/ 2（高学年）/ 3（受験）
3列目: 問題文（例: 7 × 8 = ?）
4列目: 正解（例: 56）
5〜7列目: 間違いの選択肢（3つ必要）
8列目: 解説メモ（省略可）

🔗 Google スプレッドシートのURLを入力

公開CSV URL を貼り付け

ℹ️ URLの取得方法（Googleスプレッドシート）

1. スプレッドシートを開く
2. メニュー: ファイル → 共有 → ウェブに公開
3. 「リンク」タブ → 「カンマ区切りの値（.csv）」 を選択
4. 「公開」ボタンを押してURLをコピー
5. 上の欄に貼り付けて「読み込む」を押す
